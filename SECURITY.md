# Security Policy
## Reporting a Vulnerability
If you discover a security vulnerability in SkillSync, please **do not create a public GitHub issue**. Instead, email us directly at security@mentonest.org with:
- A description of the vulnerability
- Steps to reproduce the issue
- Any potential impact or exploit scenarios

Our security team will acknowledge your email within 48 hours and work with you to validate and resolve the issue promptly.

## What to Expect
1. **Acknowledgment**: You'll receive a confirmation that we've received your report within 48 hours
2. **Investigation**: Our team will investigate the issue and determine its severity
3. **Resolution**: We'll work on a fix and coordinate with you to verify the resolution
4. **Disclosure**: We'll coordinate a public disclosure timeline once the issue is resolved

## Supported Versions
We currently provide security updates for the latest stable release and the previous major version. Older versions are not supported.

## Security Updates
Security updates are released as soon as they are validated. Watch the repository for security advisories or subscribe to our newsletter for critical updates.
